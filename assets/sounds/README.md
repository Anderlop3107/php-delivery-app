# Sonidos de Notificación Personalizados

## 1. Notificación de Pedidos Entrantes (Panel de Control de Repartidor)
* **Nombre de archivo:** `notification.mp3`
* **Ubicación:** `assets/sounds/notification.mp3`
* **Función:** Suena en bucle constante cuando se recibe un nuevo pedido en el radar.

## 2. Confirmación de Pedido Entregado
* **Nombre de archivo:** `delivered.mp3`
* **Ubicación:** `assets/sounds/delivered.mp3`
* **Función:** Suena una vez (1.5 segundos) cuando confirmas que el pedido ha sido entregado con éxito.
